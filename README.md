# Planvoro

**Onde a viagem em grupo é decidida.**

Planvoro é uma ferramenta web para grupos brasileiros decidirem a viagem juntos:
cada pessoa marca suas preferências, a IA monta um roteiro que equilibra o grupo
e explica o raciocínio citando as pessoas pelo nome, e o que não dá para
equilibrar vai para votação.
